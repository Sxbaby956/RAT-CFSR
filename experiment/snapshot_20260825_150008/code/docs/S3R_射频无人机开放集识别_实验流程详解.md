# 《Open Set Learning for RF-Based Drone Recognition via Signal Semantics》实验流程详解

## 1. 研究任务与整体路线

论文提出 S3R，用射频信号的时频谱识别无人机开放集。与只把未知样本拒绝掉的普通 OSR 不同，S3R 还尝试把被拒识的未知样本进一步聚成多个未知类别。

完整流程分三阶段：

1. **特征生成**：把原始 I/Q 射频片段转换为归一化时频谱（TFS）。
2. **语义构建**：纹理提取器 TE 学信号带宽、持续时间等纹理；位置提取器 PE 学跳频点、跳频间隔和周期等绝对/相对位置；融合成语义向量。
3. **语义分类**：用训练已知类语义的马氏距离和 3σ 离群规则自动定类边界；边界内识别为已知类，边界外先拒识，再用增强语义和聚类推断未知类别数与分组。

## 2. 数据采集和样本制作

### 2.1 DroneRFb-Spectra 数据集

- 共 24 类，覆盖 DJI、VBar、FrSky、Futaba、Taranis、RadioLink、Skydroid 七个品牌，包含一个背景类。
- 10 类在室外采集：无人机距接收机 20–150 m。
- 14 类在室内采集：无人机悬停，距接收机 5 m。
- 监测 915 MHz、2.4 GHz 和 5.8 GHz 三个 ISM 频段，接收带宽 100 MHz。
- USRP 接收增益 50 dB，使用额外增益 3 dB 的全向天线，不用功率放大器；作者称有效探测距离约 200 m。
- 原始 I/Q 按 50 ms 切片；采样率 100 MS/s，因此每段 $T=5\times10^6$ 个采样点。
- 每个片段转换为时频谱并下采样到 $512\times512$。
- 各类别样本数并不均衡，约 296–767 个；数据表中的全部类别合计约一万余样本。

数据中同时考虑飞控信号 FCS 和视频传输信号 VTS。FCS 通常带宽小于 5 MHz、持续少于 5 ms；VTS 常为 10 或 20 MHz、持续超过 10 ms且功率更高。有些无人机会关闭 VTS，故不能只依赖 VTS。

### 2.2 一段原始信号到模型输入

1. 从连续采集数据中截取 50 ms I/Q 片段。
2. 对片段做短时傅里叶变换。分析窗长度 $W=2048$，滑动步长 $R_W=1024$，窗函数为 Hamming。
3. 对每个窗独立做 FFT，并取复数幅值。
4. 计算对数功率谱：
   $$X(n,w)=20\log_{10}|\mathrm{STFT}(x)|$$
5. 对每张谱图独立做 min-max 归一化：
   $$\hat X=\frac{X-\min(X)}{\max(X)-\min(X)}$$
6. 将谱图下采样/整理为 $512\times512$，作为 TE 和 PE 的共同输入。

注意：训练集与测试集应按原始采集片段或采集序列分组后再划分，避免相邻重叠片段泄漏。论文给出类别和场景，但未明确公开训练/测试比例及拆分随机种子，复现时必须自行固定并报告。

## 3. 语义构建网络

### 3.1 纹理提取器 TE

TE 面向带宽、持续时间等局部纹理，由三条并行膨胀卷积分支 DCLs-c 构成，膨胀率分别为 $c=1,3,5$，用多尺度感受野适应 FCS/VTS 尺寸差异。

每条分支包含 $I_{max}=6$ 个特征映射级，基本操作为：

$$Z_i^c=\mathrm{MaxPool}(\mathrm{ReLU}(W_i^c*Z_{i-1}^c+b_i^c))$$

三条分支末端分别做全局平均池化，得到一维向量 $z_1,z_3,z_5$，连接成 $\tilde z_0=z_1\oplus z_3\oplus z_5$。随后通过 $J_{max}=3$ 层多层非线性网络 MNLs，形成纹理语义 $\tilde z_a$。

### 3.2 位置提取器 PE

卷积和池化具有平移不变性，可能把“纹理相同、仅频点位置不同”的同品牌无人机混淆。因此 PE 显式加入二维正弦/余弦位置编码，并同时沿时间轴、频率轴建模。

1. 给原谱图加入位置编码，得到时间方向输入 $\hat X_T$。
2. 转置谱图后再加入位置编码，得到频率方向输入 $\hat X_F$。
3. 两路各通过 $L_{max}=3$ 个自注意力模块。每层利用可学习的 $Q_l,K_l,V_l$ 计算 scaled dot-product attention；映射维度 $\gamma_l=256$，输入相关维度表中给为 $n_l=64$。
4. 将两路输出展平，并分别通过 MNLs，得到时间位置语义 $\tilde z_b$ 与频率位置语义 $\tilde z_c$。

### 3.3 语义融合

连接纹理与两路位置语义，再通过 MNLs：

$$z=\mathrm{MNLs}(\tilde z_a\oplus\tilde z_b\oplus\tilde z_c),\qquad z\in\mathbb R^D$$

论文默认 $D=128$。消融显示 32–128 是较合适区间：增大 $D$ 倾向于提升 TUR、KP，但可能降低 TKR、UP。

## 4. 已知类语义训练

### 4.1 损失一：中心损失

让同类语义靠近其动态类中心 $\mu_y$：

$$L_{cen}=\sum_i\|E(X_i;\theta)-\mu_{y_i}\|_2$$

每个 mini-batch 后，按该类样本语义与中心的平均差更新 $\mu_k$。中心更新学习率 $\alpha=10^{-4}$。

### 4.2 损失二：聚类/间隔损失

让样本远离其他已知类中心：

$$L_{clu}=\sum_i\sum_{k\ne y_i}\max(0,\vartheta-\|E(X_i;\theta)-\mu_k\|_2)$$

间隔 $\vartheta=8$。敏感性实验表明，$\vartheta$ 增大可改善 TUR/KP，但超过 8 时会损害 TKR/UP。

### 4.3 损失三：交叉熵

在语义后接 MNLs 分类器和 softmax，对训练已知类计算 $L_{ce}$，保证语义具备常规监督分类能力。

### 4.4 总训练步骤

论文默认：batch size $M=48$，SGD，最大 250 epoch，损失权重 $\eta_1=5\times10^{-3}$、$\eta_2=1$、$\eta_3=0.1$。

每个 batch 执行：

1. 输入归一化 TFS，前向经过 TE、PE 和融合层，得到 $z=E(X;\theta)$。
2. 计算 $L_{cen}$、$L_{clu}$、$L_{ce}$。
3. 组合总损失：
   $$L=\eta_1L_{cen}+\eta_2L_{clu}+\eta_3L_{ce}$$
4. 对网络参数 $\theta$ 反向传播并由 SGD 更新。
5. 按 batch 内各类样本更新对应中心 $\mu_k$。
6. 重复到 250 epoch。论文曲线显示聚类损失和交叉熵较快下降，中心损失下降较慢。

论文未报告 SGD 的动量、权重衰减、主学习率及调度器，也未给出每层卷积核/通道数；这些是严格复现必须从代码确认的项目。

## 5. 不使用未知数据的边界标定

训练完成后，固定特征提取器，收集每个已知类 $k$ 的训练语义。计算类中心 $\mu_k$、协方差矩阵 $\Sigma_k$，再求每个样本到本类中心的马氏距离：

$$d(z,\mu_k)=\sqrt{(z-\mu_k)^T\Sigma_k^{-1}(z-\mu_k)}$$

对类别 $k$ 的 $N_k$ 个距离执行：

1. 将距离从大到小排列。
2. 计算本类距离集合的标准差 $\sigma_k$。
3. 从最大距离起遍历，以 3σ 离群规则跳过异常点。
4. 把第一个不再属于离群值的距离作为核心阈值 $\Phi_k^*$。
5. 定义类域 $R_k=\{z:d(z,\mu_k)<\Phi_k^*\}$。

该过程只使用已知训练数据，不需要拿未知测试样本做网格搜索。实现时应对协方差矩阵加小的对角正则项，防止样本少或 $D$ 较大时不可逆；论文没有明确该数值。

## 6. 在线已知/未知判定

对每个测试谱图 $X_t$：

1. 计算原始语义 $z_t=E(X_t;\theta)$。
2. 计算其到所有已知类中心的马氏距离。
3. 若至少落入一个类域 $R_k$，判为已知；标签取最近中心：
   $$\hat y_t=\arg\min_{k\in\mathcal K}d(z_t,\mu_k)$$
4. 若不落入任何 $R_k$，判为未知并暂存到未知缓冲区 $\mathcal D$。

若一个样本同时进入多个类域，最近中心规则仍可消解冲突。

## 7. 未知类别的精细聚类

### 7.1 增强语义

原始语义为已知类监督分类而优化，深层 MNLs 可能丢弃对已知类无用、但能区分新类的抽象特征。作者因此把 TE 中间 DCL 输出连接回来：

$$z^a=z\oplus\tilde z_0$$

所有未知样本使用增强语义聚类。论文实验表明这使未知准确率提高 3.46%，UP 提高 15.83%。

### 7.2 缓冲与“只有一个未知类”的判断

当未知缓冲区达到预设容量 $N_U$ 后：

1. 对缓冲中的增强语义计算内部离群阈值 $\Phi_U^*$。
2. 若 $\Phi_U^*\leq\max_k\Phi_k^*$，认为未知样本的离散程度不超过已知类常见范围，全部归为同一个未知类，即 $u=1$。
3. 否则进入未知类别数估计。

论文未给 $N_U$ 的默认数值。它直接影响在线延迟和聚类稳定性，复现时应设定并做敏感性分析。

### 7.3 推断未知类数并聚类

当可能有多个未知类时：

1. 对候选类别数 $u=2,3,\ldots,N_U$，用 k-means 将缓冲区划分成 $u$ 簇 $C_u$。
2. 用 Silhouette Coefficient 评价每个 $C_u$。对样本 $z_t$，$a(z_t)$ 是同簇平均距离，$b(z_t)$ 是到最近其他簇的平均距离，轮廓值为 $(b-a)/\max(a,b)$。
3. 论文用相邻轮廓系数的二阶变化寻找极值：
   $$u^*=\arg\max_u|S(C_{u-1})+S(C_{u+1})-2S(C_u)|$$
4. 以 $u^*$ 再运行一次 k-means，输出最终未知分组 $C_1,\ldots,C_{u^*}$。

候选上界直接取 $N_U$ 在工程上可能产生单样本簇并使轮廓系数无定义；可靠实现应把候选范围限制在 $2\leq u\leq N_U-1$，处理空簇/单样本簇，并固定 k-means 初始化次数与随机种子。这属于复现所需防护，论文算法未展开。

## 8. 开放集场景划分

论文用表 I 的字母 A–X 指代 24 类，设置六种不同规模场景：

- 场景 I：18 已知、6 未知。
- 场景 II：20 已知、4 未知。
- 场景 III：22 已知、2 未知。
- 场景 IV：23 已知、1 未知。
- 场景 V：16 已知、8 未知。
- 场景 VI：14 已知、10 未知。

场景 I 用于详细准确率比较；六个场景共同检验已知/未知类别数量变化时的泛化。另从场景 I 改造 I-A、I-B、I-C，每个均为 18 已知、6 未知，但更换未知类别组合，用于检验对具体未知组合的敏感性。复现时应直接按论文表 IV、VI 保存字母索引列表，不要每次随机重抽。

## 9. 评价指标与统计方式

记 TK/TU 为被正确接受为已知/拒绝为未知的测试样本数，FK/FU 为被错误接受为已知/错误拒绝为未知的样本数：

$$TKR=\frac{TK}{TK+FU},\qquad TUR=\frac{TU}{TU+FK}$$

进一步定义：

$$KP=\frac{CK}{TK+FK},\qquad UP=\frac{CU}{TU+FU}$$

- CK：已知测试样本不仅被接受，而且精确分类正确的数量。
- CU：同一真实未知类的样本被聚在一起的数量；只有当该真实类在对应簇中占至少 50% 时，才计为正确未知。
- 同时报告逐类 known accuracy、unknown accuracy 及其平均值。

这里的 UP 不只是“拒识精度”，还包含未知类聚类正确性，因此 OpenMax/UIOS 等只拒识、不细分未知类别的方法不能给出 unknown accuracy 和 UP。

## 10. 对比实验如何执行

### 10.1 比较方法

- SR2CNN：需要已知和未知先验数据，能细分未知类。
- OpenMax、UIOS：只需已知训练数据，能拒识但不能细分未知类。
- Isolation Forest、One-class SVM、LOF：在 S3R 语义上做异常检测，只执行接受/拒绝。

SR2CNN 使用 $\beta=0.4$，在测试集网格搜索阈值以最大化 $0.4\,TKR+0.6\,TUR$。IF、One-class SVM、LOF 的超参数也在测试集网格搜索到最优。因为这些检测器依赖随机种子，论文重复 100 次并报告最佳结果。

这一设置偏向比较方法且使用测试集调参，不等同于严格无泄漏的现实部署。若做规范复现，建议同时提供“原论文协议结果”和“独立验证集调参、测试集只评一次”的结果。

### 10.2 主结果实验

1. 在场景 I 训练一次 S3R（训练只含 18 个已知类）。
2. 用已知训练语义标定每类 3σ 阈值。
3. 在含 18 已知和 6 未知的测试集上执行已知识别、未知拒识与缓冲聚类。
4. 计算逐类准确率、平均已知/未知准确率、TKR、TUR、KP、UP，与 SR2CNN/OpenMax/UIOS 比较。
5. 论文相对次优方法报告：平均已知准确率 +14.18%、平均未知准确率 +18.81%、TKR +13.61%、UP +17.99%。

### 10.3 泛化实验

按场景 I–VI 分别重训模型、重新计算类中心/协方差/阈值并测试，绝不能沿用另一个场景的阈值。再对 I-A/I-B/I-C 重复，以观察只更换未知组合时指标波动。论文中 S3R 在六场景的 TUR 均超过 95%。

### 10.4 消融与敏感性实验

1. **TE/PE 消融**：完整 TE+PE、仅 TE、仅 PE。保持训练设置相同。完整模型的 known accuracy/unknown accuracy/TKR/TUR/KP/UP 分别为 0.9517/0.8763/0.9508/0.9566/0.9201/0.8763；仅 TE 的未知准确率为 0.7180，仅 PE 为 0.4379。
2. **语义维度 $D$**：扫描多个维度，比较四个 OSR 指标，最后取 128。
3. **信号长度**：改变输入片段长度；作者观察长度越长，全部指标越好，因为携带更多射频特征。
4. **训练样本数**：逐步增加每类训练样本；TKR/UP 明显提高，但 TUR/KP 略降。
5. **间隔 $\vartheta$**：扫描间隔，最终选 8。
6. **边界分类器消融**：在同一套 S3R 语义上比较 3σ 离群分类器、IF、One-class SVM、LOF，隔离特征差异，只比较判别器。
7. **增强语义消融**：未知聚类分别使用 $z$ 与 $z\oplus\tilde z_0$，验证中间抽象特征的贡献。
8. **可视化**：对场景 I 测试语义降维绘图，比较 S3R、SR2CNN、OpenMax、UIOS 中已知/未知簇重叠情况。

## 11. 复现中最容易出错的环节

- **数据泄漏**：50 ms 邻近片段可能高度相关；必须按连续采集段而非随机图片切分。
- **功率归一化**：论文逐谱图 min-max，旨在消除距离导致的功率差；若改成全数据集归一化，会改变任务特征。
- **协方差稳定性**：马氏距离需要可逆协方差；需记录正则化或伪逆策略。
- **背景类定义**：背景包含环境 Wi-Fi 与 Bluetooth，作为数据表中的已知类别之一时要按具体场景表处理。
- **未知精细识别**：不能只算 unknown rejection 就声称复现了 UP；还必须完成增强语义、未知数估计、k-means 和 50% 主导簇计分。
- **未知缓冲容量**：论文没有默认 $N_U$，结果会随容量和未知样本到达顺序变化，应报告多种容量/顺序。
- **统计口径**：论文对随机异常检测器做 100 次并报最佳值，而不是均值；复现时必须注明，否则不可直接对表。
- **缺失实现参数**：卷积通道、核大小、padding、MNLs 层宽、主 SGD 学习率等正文未给出，应优先查看作者公开代码；若自行设定，需单列“实现假设”。
