# 融合架构与两篇论文的继承关系说明（修订版）

![RAT-CFSR 无线信号体制开放集识别整体架构](C:/Users/thinkpad/Desktop/zjm/RAT-CFSR_整体架构图.png)

## 1. 总体继承关系

最终 EI 简化架构不是将 S3R 和 CFSR 完整串联，而是分别保留两篇论文中最适合无线信号体制开放集识别的核心部分：

```text
CFSR：原始 I/Q 骨干 + 类投影空间 + 类 AE + 重构拒识
                              ↑
              门控融合 + 重构排序 + 误差校准
                              ↓
S3R：STFT 时频谱 + 谱图归一化 + 多尺度纹理提取
```

- CFSR 主要解决“如何建立类专属空间并拒识未知体制”；
- S3R 主要解决“如何从射频信号构建可区分的时频语义”；
- 本文新增的门控融合负责连接两类表示，重构排序和误差校准负责提高训练与推理的一致性。

## 2. 模块来源对照

| 最终模块 | 来源 | 继承或改造方式 |
|---|---|---|
| 原始 I/Q 一维分支 | CFSR | 沿用原始 I/Q 输入和一维残差特征提取 |
| STFT 时频谱 | S3R | 将同一 I/Q 窗口转换为对数功率谱 |
| 单谱图归一化 | S3R | 减少接收功率、距离和增益差异 |
| 多尺度二维卷积 | S3R | 使用不同膨胀率提取局部和大尺度时频纹理 |
| 线性维度对齐 | 本文明确化 | 将时域和时频语义映射到相同维度 |
| 自适应门控融合 | 本文新增 | 动态学习两个分支的样本级权重 |
| 每类投影器 | CFSR | 为每个已知信号体制建立独立特征空间 |
| 每类瓶颈 AE | CFSR + 本文改造 | 保留类重构思想，并通过瓶颈防止恒等映射 |
| 正确类重构损失 | CFSR | 使正确体制支路产生较小重构误差 |
| 重构排序损失 | 融合改造 | 结合 CFSR 重构误差与 S3R 类间分离思想 |
| 类别条件误差校准 | 本文明确化 | 解决不同类 AE 原始误差尺度不可直接比较的问题 |
| 每类拒识阈值 | CFSR | 使用独立已知校准集设置类别阈值 |

## 3. 从 CFSR 继承的内容

### 3.1 原始 I/Q 骨干

CFSR 直接输入 I/Q 双通道序列，通过修改的一维 ResNet18 提取潜在特征：

$$f_{iq}=B(x)$$

融合架构保留这一思想。I/Q 分支主要学习瞬时幅相变化、调制细节、符号变化和短时结构。

### 3.2 每类独立投影空间

CFSR 为每个已知类配置投影器 $p_k$。融合架构同样将最终融合语义映射到不同体制的类空间：

$$h_k=p_k(\bar z)$$

其中 $\bar z$ 是 L2 归一化后的融合语义。若已知类为 NR、LTE 和 Wi-Fi，则分别建立 $p_{NR}$、$p_{LTE}$ 和 $p_{WiFi}$。

### 3.3 类专属自编码器

CFSR 使用每类 AE 拟合该类特征分布。融合架构保留这一核心机制，但将 AE 明确限制为小型瓶颈结构，例如：

```text
64 → 16 → 64
```

类 $k$ 的平均 L1 重构误差为：

$$e_k(x)=\frac{1}{d_p}\|h_k-AE_k(h_k)\|_1$$

瓶颈、输入扰动以及不使用跳跃连接，是为了防止 AE 对所有输入形成恒等映射。

### 3.4 其他已知类作为伪未知

CFSR 在类别 $k$ 的视角下，把其他已知类别当成类外样本。融合架构没有继续使用每类二分类 MLP，而是把这一思想改造成重构排序损失：

$$L_{margin}=\frac{1}{M}\sum_i\max\left(0,m+e_{y_i}(x_i)-\min_{k\neq y_i}e_k(x_i)\right)$$

它要求正确体制的重构误差低于最容易混淆的错误体制。

### 3.5 类别条件阈值

CFSR 使用每类重构误差分布设置独立阈值。融合架构保留每类阈值，但不再直接比较不同 AE 的原始误差，而是先进行类别条件校准，再确定候选类别和拒识结果。

## 4. 从 S3R 继承的内容

### 4.1 STFT 和对数功率谱

S3R 将原始射频信号转换为时频功率谱：

$$X(n,f)=20\log_{10}(|\operatorname{STFT}(x)|+\epsilon)$$

融合架构使用相同处理生成第二种信号视图。时频谱能够表现占用带宽、子载波、谱边缘、突发持续时间和帧状结构。

### 4.2 单样本谱图归一化

S3R 使用谱图归一化降低功率差异。融合架构保留该步骤，防止模型将距离、接收增益或固定功率水平当成类别特征。

### 4.3 多尺度纹理提取器

S3R 的 TE 使用不同膨胀率的卷积分支，例如 1、3、5。融合架构保留这一设计：

- 小尺度分支关注子载波和局部纹理；
- 中尺度分支关注短时突发和符号结构；
- 大尺度分支关注整体带宽和较长时序结构。

三个分支经过池化和拼接形成时频语义 $f_{tf}$。

### 4.4 类间分离思想

S3R 使用中心损失和聚类间隔使同类语义紧凑、不同类语义分离。为控制 EI 论文工作量，融合架构不直接照搬中心损失和马氏距离分类器，而是将类间分离思想迁移到重构误差空间：

$$e_y+m<e_k,\qquad k\neq y$$

## 5. 本文新增和明确化的内容

### 5.1 维度对齐后的门控融合

时域特征和时频特征不能在维度不一致时直接相加。因此先通过独立线性层映射：

$$\tilde z_{iq}=W_{iq}f_{iq}+b_{iq}$$

$$\tilde z_{tf}=W_{tf}f_{tf}+b_{tf}$$

然后计算样本级门控权重：

$$[g_{iq},g_{tf}]=\operatorname{softmax}(\operatorname{MLP}_g[\tilde z_{iq};\tilde z_{tf}])$$

最终语义为：

$$z=\operatorname{LayerNorm}(g_{iq}\tilde z_{iq}+g_{tf}\tilde z_{tf})$$

训练时增加模态屏蔽，避免门控长期只选择一个分支。

### 5.2 瓶颈和有界类特征

为避免 AE 把所有类别都重构得很好，修订版增加：

- 融合语义 L2 归一化；
- 投影器末端 `tanh`；
- 明显低维的 AE 瓶颈；
- 无跳跃连接；
- 小幅输入噪声或 dropout。

这些措施并非改变 CFSR 的基本思想，而是使其在简化实现中更稳定。

### 5.3 类别条件误差校准

不同 AE 的原始误差尺度可能不同，因此以下原始规则不够严谨：

$$k^*=\arg\min_k e_k(x)$$

修订版先用独立已知校准集得到类别 $k$ 的匹配误差集合：

$$E_k^{cal}=\{e_k(x_i):y_i=k\}$$

再通过经验累积分布转换误差：

$$s_k(x)=F_k(e_k(x))$$

候选类别改为：

$$k^*=\arg\min_k s_k(x)$$

最终判断为：

$$\hat y=
\begin{cases}
k^*,&s_{k^*}(x)\leq\tau_{k^*}\\
\mathrm{unknown},&s_{k^*}(x)>\tau_{k^*}
\end{cases}$$

如果使用经验 CDF，默认可从 $\tau_k=0.95$ 开始。阈值敏感性实验比较 0.90、0.95、0.99。

## 6. 最终训练目标

修订版只保留三项损失：

$$L=L_{ce}+\lambda_{rec}L_{rec}+\lambda_{margin}L_{margin}$$

- $L_{ce}$：训练融合语义的已知类判别能力；
- $L_{rec}$：最小化正确体制支路的重构误差；
- $L_{margin}$：扩大正确体制与最难错误体制之间的误差间隔。

辅助分类头只在训练阶段提供 $L_{ce}$。最终开放集候选类别和未知拒识均由校准重构分数完成。

## 7. 最终推理流程

1. 对 I/Q 执行统一采样率、实际时长和功率归一化处理。
2. I/Q 分支得到 $f_{iq}$。
3. STFT 多尺度分支得到 $f_{tf}$。
4. 映射两个分支到相同维度并门控融合，得到 $z$。
5. 对 $z$ 做 L2 归一化并输入所有类投影器和瓶颈 AE。
6. 计算 $K$ 个原始重构误差 $e_1,\ldots,e_K$。
7. 根据每类独立校准分布转换为 $s_1,\ldots,s_K$。
8. 选择 $k^*=\arg\min_k s_k$。
9. 若 $s_{k^*}\leq\tau_{k^*}$，输出已知体制 $k^*$；否则输出 unknown。

## 8. 未纳入 EI 简化版的模块

以下内容不属于最终架构：

- S3R 完整绝对位置编码和双向自注意力 PE；
- S3R 的马氏距离 3σ 类域；
- S3R 的未知类别数估计和 k-means 聚类；
- 额外周期结构编码器；
- CFSR 完整 $K\times K$ 误差矩阵训练；
- CFSR 每类开放集二分类头；
- 共享 AE Adapter；
- 分类能量、马氏距离和重构误差三分数组合；
- 共形预测和 HDBSCAN。

这些模块可作为后续扩展，但不应继续出现在当前模型图、损失函数或主实验中。

## 9. 可用于论文的贡献表述

1. 提出面向无线体制开放集识别的双视图语义网络，联合利用原始 I/Q 和多尺度时频纹理。
2. 设计维度对齐后的自适应门控融合，根据不同信号动态调整时域与时频表示的贡献。
3. 将类特征空间重构用于未知体制拒识，并通过瓶颈 AE、重构排序损失和类别条件误差校准提高类空间可分性与推理可靠性。

## 10. 最终总结

- **CFSR 负责开放集骨架**：I/Q 骨干、类投影空间、类 AE、重构误差和类别阈值。
- **S3R 负责时频语义**：STFT、谱图归一化和多尺度纹理提取。
- **本文负责融合与稳定化**：维度对齐、门控融合、瓶颈约束、重构排序以及类别条件误差校准。

修订后的模型不再直接比较不同 AE 的原始重构误差，而是比较校准后的类别条件分数；同时通过瓶颈和有界特征降低 AE 恒等重构风险。训练目标、校准过程和推理规则因此保持一致。
