# 《Class Feature Space Reconstruction for Automatic Modulation Open Set Recognition》实验流程详解

## 1. 实验目标与核心思想

论文研究自动调制开放集识别（open-set recognition, OSR）：训练时只出现已知调制类别，测试时既有已知类别，也有训练中从未出现的未知类别。模型需要同时完成两件事：正确细分已知调制类型，并把未知调制统一拒识为“unknown”。

作者提出 CFSR（Class Feature Space Reconstruction）。它不把所有类别压进同一个特征空间，而是为每个已知类建立独立的投影空间和类专属自编码器（AE）。分类依据是“样本经该类投影后，能否被该类 AE 低误差重构”；开放集判定则通过训练集重构误差形成每类阈值。

## 2. 信号与任务定义

接收信号模型为：

$$r(n)=[s(n)*h(n)]e^{j(2\pi\Delta fn+\theta_0)}+w(n),\quad n=0,\ldots,L-1$$

其中 $h(n)$ 为时变信道冲激响应，$w(n)$ 为零均值高斯白噪声，$\Delta f$ 和 $\theta_0$ 分别为频偏和相偏。输入是 I/Q 双通道序列。

训练集只包含 $K$ 个已知类，标签为 $1,\ldots,K$；测试集包含已知样本和未知样本，未知类别统一记作 $K+1$。

## 3. 数据准备

### 3.1 主实验：HKDD12

- 12 种调制：BPSK、QPSK、8PSK、OQPSK、16QAM、32QAM、64QAM、4PAM、8PAM、2FSK、4FSK、8FSK。
- SNR：-20 dB 到 20 dB，步长 2 dB，共 21 个 SNR 点。
- 单样本长度：512；数据形式为 I/Q 双通道。
- 每个“调制类别 × SNR”组合：训练 1000 个样本，测试 500 个样本，即训练测试比 2:1。
- 总样本数：378,000。
- 默认开放集划分：7 个类别作为已知类，剩余 5 个作为未知类。
- 所有结果采用 5 折交叉验证，以轮换已知/未知类别组合，避免结论依赖某一次固定类别划分。

### 3.2 大规模数据实验

**RML2016.10b**

- 总样本数 1,200,000。
- 10 类：AM-DSB、WBFM、BPSK、QPSK、8PSK、16QAM、64QAM、BFSK、CPFSK、PAM4。
- SNR 为 -20 到 18 dB，步长 2 dB。
- 信号长度 128，训练测试比 1:1。
- 开放集划分为 7 个已知类、3 个未知类，并做 5 折交叉验证。

**HKDD36**（论文表格标题有一处写作 HKDD64，但正文和数据列均指 HKDD36）

- 总样本数 1,404,000，36 种调制。
- SNR 为 -20 到 30 dB，步长 2 dB。
- 信号长度 1024，训练测试比 2:1。
- 开放集划分为 26 个已知类、10 个未知类，并做 5 折交叉验证。

### 3.3 一次可复现的数据划分流程

1. 选定一个数据集及本折的已知类别集合 $\mathcal K$；其余类别组成未知集合 $\mathcal U$。
2. 训练阶段只读取 $\mathcal K$ 中的训练样本，绝不能把未知类样本、标签或统计量用于训练。
3. 测试集同时放入 $\mathcal K$ 和 $\mathcal U$ 的测试样本；评价未知检测时，把所有 $\mathcal U$ 样本视作统一未知类。
4. 按各自 SNR 分组评价，绘制 AUROC-SNR 和 OSCR-SNR 曲线。
5. 更换类别划分完成 5 折，最后报告各折的均值。论文没有列出每折确切类别名单，复现时应保存随机种子与每折类别清单。

## 4. 模型组成

### 4.1 主干网络

用修改的一维 ResNet18 作为骨干网络 $B$，输入原始 I/Q 信号 $x$，输出共享潜表示：

$$z=B(x)$$

论文未给出修改后每层通道数、卷积核、步长及 $z$ 的维度；严格复现需参考作者代码或自行固定这些实现并记录。

### 4.2 类专属投影空间

为每个已知类别 $k$ 创建一个投影 MLP $p_k$，将共享表示映射到该类独立空间：

$$z_k^p=p_k(z)$$

因此 $K$ 个已知类对应 $K$ 个互相独立的投影 MLP。

### 4.3 类空间自编码器

每个已知类再配一个对称 MLP 编码器/解码器 $AE_k=D_k\circ E_k$。将样本在投影空间 $i$ 中的特征交给类 AE $j$ 重构，得到：

$$\hat z_{i,j}^p=AE_j(z_i^p)$$

以 L1 距离计算重构误差：

$$e_{i,j}=\|p_i(z)-AE_j(p_i(z))\|_1$$

对一个样本可形成 $K\times K$ 的误差矩阵。第 $i$ 行是投影空间 $i$ 中各 AE 的误差，第 $j$ 列是 $AE_j$ 在所有投影空间上的误差。

### 4.4 二分类头

每个类空间还有一个二分类 MLP $fc_k$。样本经过 $p_k$ 和 $E_k$ 后形成流形嵌入：

$$z_{i,k}^{m}=E_k(p_k(B(x_i)))$$

对 $AE_k$ 而言，标签属于 $k$ 的样本为正类，batch 中所有其他已知类样本均被视为“伪未知”负类。这是在完全不使用真实未知数据的前提下向训练注入开放集监督的关键。

## 5. 训练流程

### 5.1 初始化

1. 构建一个一维 ResNet18 骨干。
2. 按已知类数 $K$ 创建 $K$ 个投影 MLP、$K$ 个类空间 AE 和 $K$ 个二分类 MLP。
3. 初始化全部参数；设置 AdamW、初始学习率 0.003、batch size 64、最大 50 epoch、余弦退火学习率。
4. 设置总损失权重 $\alpha$。论文给出损失形式但未报告 $\alpha$ 的具体数值，复现时必须补充并在验证集上固定。

### 5.2 每个 mini-batch 的前向计算

对 batch 中每个样本 $x_i$：

1. 用骨干提取 $z_i=B(x_i)$。
2. 将 $z_i$ 分别输入所有 $p_1,\ldots,p_K$，得到 $K$ 个类空间特征。
3. 将每个投影结果送入全部 $K$ 个 AE，计算 $K\times K$ 个 L1 重构误差。
4. 在每一个固定 AE 列中，对负重构误差做 softmax。训练目标是：无论观察哪个 AE，真实类别 $y_i$ 对应的投影空间都应给出最小误差。

类别特征空间重构损失为负对数似然 $L_r$。直观上，它训练投影器把“属于类别 $k$ 的信息”集中到第 $k$ 个投影空间，并让误差矩阵中真实类别对应的行更小。

### 5.3 开放集损失

对每个类空间 $j$：

1. 计算 $z^m_{i,j}=E_j(p_j(B(x_i)))$。
2. 若 $y_i=j$，二分类目标 $\hat y_{ij}=1$；否则为 0。
3. 用 $fc_j(z^m_{i,j})$ 预测样本是否属于该类。
4. 在 batch 和全部类空间上累计二元交叉熵，得到 $L_o$。

这一步使用“其他已知类相对于当前类就是未知”的视角学习类内/类外边界，无须生成未知样本。

### 5.4 更新参数

总损失为：

$$L_{cfsr}=L_r+\alpha L_o$$

对骨干、投影 MLP、AE 以及二分类头联合反向传播，用 AdamW 更新；余弦计划调整学习率。重复到 50 epoch。论文算法把二分类头用于 $L_o$，但最终输出列表只写骨干、投影器和 AE；推理决策也只使用重构误差，因此二分类头可视作训练期辅助头。

## 6. 阈值标定与推理

### 6.1 每类阈值标定

训练结束后，对训练集中类别 $k$ 的所有样本计算其“匹配支路”误差：

$$e_k(x)=\|p_k(B(x))-AE_k(p_k(B(x)))\|_1$$

由这些误差的经验分布确定类别阈值 $\hat\tau_k$。论文描述为预先设定 $\eta\%$ 的训练样本被视作未知，再据此取经验阈值；公式的文字方向存在一定歧义，且未报告 $\eta$ 数值。实现时应明确使用哪个分位点，并在代码和报告中记录。常见且与拒识逻辑一致的实现是取匹配误差的高分位数，使少量高误差训练样本落在阈值外。

### 6.2 单样本推理

对测试样本 $x$：

1. 计算 $z=B(x)$。
2. 只取误差矩阵对角线，即计算每个匹配支路：
   $$e_k=d(p_k(B(x)),AE_k),\quad k=1,\ldots,K$$
3. 找到误差最小的候选类 $k^*=\arg\min_k e_k$；等价地，也可对 $-e_k$ 做 softmax 后取最大概率。
4. 若 $e_{k^*}\leq\hat\tau_{k^*}$，输出已知类 $k^*$。
5. 否则输出统一未知类 $K+1$。

注意：阈值比较应使用候选类 $k^*$ 自己的阈值，不能使用全局统一阈值。

## 7. 评价实验的具体执行

### 7.1 指标

- AUROC：改变拒识阈值，统计已知/未知二分类的真阳性率和假阳性率并求 ROC 面积；不依赖某个固定阈值。
- OSCR：联合衡量“已知样本被正确细分”和“未知样本被拒识”，以正确分类率对未知假阳性率形成曲线并求面积。
- 两者均越高越好。计算时须统一哪一侧是 positive，并确认分数方向；CFSR 的未知分数可用最小重构误差，值越大越像未知。

### 7.2 主基线比较

在 HKDD12 的各个 SNR 上比较 OpenMax、CROSR、CGDL、PROSER、ARPL、CSSR 和 CFSR。

- 公平性要求：除 CROSR、CGDL 因原方法结构需要而保留原网络外，其余方法使用相同的修改版一维 ResNet18 骨干。
- 所有方法使用同样数据划分、学习率策略和运行环境。
- 对每个 SNR、每折分别计算 AUROC/OSCR，再汇总 5 折结果并画曲线。

### 7.3 消融实验

训练三种配置：完整 $L_r+\alpha L_o$、去掉 $L_r$、去掉 $L_o$。其余设置保持完全相同，在 HKDD12 各 SNR 上比较 AUROC 和 OSCR。论文观察到完整模型最佳；去掉 $L_o$ 后下降尤其明显，说明“把其他已知类当伪未知”的训练信号对未知拒识很关键。

### 7.4 Openness 实验

在 HKDD12 中固定总类别数 $K+U=12$，改变已知类数 $K=9,7,5,3$，未知数相应为 3、5、7、9。开放度定义为：

$$Openness=1-\sqrt{\frac{2K}{2K+U}}$$

对应开放度约为 0.074、0.141、0.233、0.367。为减少单个噪声点的随机性，论文只对 10–20 dB 区间的结果取平均，再报告 AUROC/OSCR。每个 $K$ 仍需做类别轮换，避免只测试一个容易的未知集合。

### 7.5 大规模数据验证

按第 3.2 节分别在 RML2016.10b 和 HKDD36 上重做全 SNR 曲线、基线比较及 5 折交叉验证。RML2016.10b 检查大样本条件，HKDD36 检查多类别、特征空间拥挤条件。

## 9. 结果解读与注意事项

- CFSR 在中高 SNR 上优势最明显；极低 SNR 时，各方法都受噪声限制。
- 多个数据集在约 -5 dB 的 AUROC 出现凹口。作者解释这是信号从被噪声淹没向可辨识过渡的临界区，已知/未知最易混淆。
- 开放度增加后全部方法下降，但 CFSR 仍领先；例如 HKDD12 的 $K=3$ 时 AUROC/OSCR 为 74.99%/74.65%。
- HKDD36 的中等 SNR 下，CFSR 的 AUROC 并非始终胜过 PROSER/ARPL，说明多类别场景中的全局分数分离仍有限；不能只挑有利区间下结论。
- 阈值只能由训练已知样本标定。若用真实未知测试数据调阈值，就破坏了论文所声称的“训练阶段无未知数据”条件。
