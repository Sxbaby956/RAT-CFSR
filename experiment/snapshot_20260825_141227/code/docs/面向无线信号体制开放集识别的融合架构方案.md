# 面向无线信号体制开放集识别的融合架构方案（EI 会议修订版）

![RAT-CFSR 无线信号体制开放集识别整体架构](C:/Users/thinkpad/Desktop/zjm/RAT-CFSR_整体架构图.png)

## 1. 方案定位

本方案面向 5G NR、LTE、Wi-Fi、DVB-T、Bluetooth 等无线信号体制的开放集识别。训练阶段只使用已知体制，测试阶段既要正确区分已知体制，也要拒识训练时没有出现的未知体制。

考虑到目标是完成一篇一般 EI 会议论文，本修订版只保留一条清晰的研究主线：

> 使用原始 I/Q 与 STFT 时频谱构建双视图语义，通过门控机制融合，再利用类特征空间和瓶颈自编码器产生类别条件重构误差，最后经类别条件校准完成已知分类与未知拒识。

本版本不再包含周期编码器、相对位置 Transformer、共享 AE Adapter、共形预测和未知类聚类。这些内容可以作为未来工作，避免模型和实验规模超过 EI 会议论文所需范围。

## 2. 最终整体架构

```text
                         ┌─ 1D CNN/ResNet ─ 线性映射 ─ z_iq ─┐
原始 I/Q ─ 统一预处理 ──┤                                  │
                         └─ STFT ─ 多尺度2D CNN ─ 映射 ─ z_tf ┤
                                                            │
                                  自适应门控融合 + LayerNorm
                                             │
                                             z
                                             │
                           ┌─────────────────┼─────────────────┐
                           ▼                 ▼                 ▼
                         p_1(z)            p_2(z)            p_K(z)
                           │                 │                 │
                    瓶颈 AE_1         瓶颈 AE_2          瓶颈 AE_K
                           │                 │                 │
                          e_1               e_2               e_K
                           │                 │                 │
                    类别条件校准      类别条件校准      类别条件校准
                           │                 │                 │
                          s_1               s_2               s_K
                           └─────────────────┼─────────────────┘
                                             │
                                  k*=argmin_k s_k(x)
                                             │
                              s_k*(x) <= tau_k* ?
                              ├─ 是：已知体制 k*
                              └─ 否：Unknown
```

## 3. 任务定义

训练集只包含 $K$ 个已知体制：

$$D_{tr}=\{(x_i,y_i)\},\qquad y_i\in\{1,\ldots,K\}$$

从已知类数据中独立留出校准集 $D_{cal}$，用于计算每类误差分布和拒识阈值。测试集同时包含已知体制和未知体制：

$$D_{te}=D_{known}\cup D_{unknown}$$

模型输出为：

$$\hat y\in\{1,\ldots,K,\mathrm{unknown}\}$$

实验必须区分：

- **未知体制**：例如训练已知为 LTE、Wi-Fi，测试未知为 5G NR；
- **未知采集域**：体制已知，但日期、地点、基站、频段或接收设备未见过。

模型应拒识未知体制，但不应仅因为采集域变化就拒绝已知体制。

## 4. 数据预处理

### 4.1 录音和窗口划分

1. 以完整录音、采集 session、日期或基站为单位划分训练、校准和测试集。
2. 完成集合划分后，再从各自录音中截取窗口。
3. 同一条连续录音产生的所有窗口必须位于同一集合，不能随机分散到训练集和测试集。
4. 窗口重叠率建议不超过 50%，并记录窗口起止位置。

窗口级随机划分会把相邻且高度相似的 I/Q 片段同时放入训练和测试，容易造成虚高结果，是本任务最需要避免的数据泄漏。

### 4.2 统一采样率和实际时长

公开数据中不同体制可能具有不同原始采样率。例如 POWDER 数据中的 Wi-Fi 和 LTE/NR 采样率并不完全相同。如果直接输入网络，模型可能只根据采样率或频谱分辨率判断类别。

预处理步骤应包括：

1. 将信号频移到基带中心；
2. 重采样到统一采样率；
3. 按相同实际时间长度截取窗口；
4. 移除直流分量；
5. 对单窗口执行 RMS 功率归一化：
   $$x' = \frac{x-\operatorname{mean}(x)}{\sqrt{\operatorname{mean}(|x|^2)}+\epsilon}$$
6. 将复数信号整理为 $2\times L$ 的 I/Q 双通道张量。

输入模型的元数据中不能包含文件名、类别固定采样率或类别固定中心频率。

### 4.3 窗口长度

5G NR、LTE 和 Wi-Fi 都可能表现为 OFDM。如果窗口太短，只能观察普通数据符号，模型可能无法获得足够的体制结构。

建议至少比较两种窗口：

- 短窗口：学习局部调制、相位和子载波纹理；
- 长窗口：覆盖更多突发、前导或帧级结构。

窗口长度按真实持续时间设置，而不是只按采样点数设置。最终选择应由已知验证集确定，并把窗口长度敏感性作为一项补充实验。

## 5. 双视图语义提取

### 5.1 原始 I/Q 时域分支

使用轻量一维 ResNet 或 TCN 提取：

- 瞬时幅度和相位变化；
- 调制与符号变化；
- 短时突发结构；
- 信道和频偏影响下的局部模式。

得到原始时域特征 $f_{iq}$ 后，用线性层投影到统一维度 $d$：

$$\tilde z_{iq}=W_{iq}f_{iq}+b_{iq},\qquad \tilde z_{iq}\in\mathbb R^d$$

推荐初始维度 $d=128$。

### 5.2 STFT 时频分支

对同一 I/Q 窗口计算短时傅里叶变换：

$$X(n,f)=20\log_{10}(|\operatorname{STFT}(x)|+\epsilon)$$

每张谱图独立执行稳健归一化或 min-max 归一化。然后使用三个并行膨胀卷积分支，初始膨胀率设置为 1、3、5，提取不同尺度的：

- 占用带宽与谱边缘；
- 子载波和局部频谱纹理；
- 突发长度和时间占用模式；
- 较大尺度的帧状结构。

三个分支经过全局平均池化和拼接，形成 $f_{tf}$，再映射到相同维度：

$$\tilde z_{tf}=W_{tf}f_{tf}+b_{tf},\qquad \tilde z_{tf}\in\mathbb R^d$$

### 5.3 自适应门控融合

先连接两个已经对齐维度的语义：

$$u=[\tilde z_{iq};\tilde z_{tf}]$$

由两层 MLP 计算两个标量门控权重：

$$[g_{iq},g_{tf}]=\operatorname{softmax}(\operatorname{MLP}_g(u))$$

融合语义为：

$$z=\operatorname{LayerNorm}(g_{iq}\tilde z_{iq}+g_{tf}\tilde z_{tf})$$

训练时以 10%–20% 的概率随机屏蔽一个分支，避免门控网络长期只依赖 I/Q 或 STFT 单一分支。实验中应记录两个门控权重的均值和分布，检查是否发生单分支塌缩。

### 5.4 已知类辅助分类头

在融合语义 $z$ 后连接线性分类头，输出 $K$ 类 logits，并计算交叉熵损失 $L_{ce}$。

该分类头主要用于训练阶段增强融合语义的闭集判别性。最终开放集推理仍以校准后的类重构分数为主。实验中需要单独报告“辅助分类头推理”和“类重构推理”的结果，说明重构模块是否真正贡献了开放集性能。

## 6. 类特征空间和瓶颈自编码器

### 6.1 类投影器

为每个已知体制 $k$ 配置一个轻量投影器：

$$h_k=p_k(z),\qquad h_k\in\mathbb R^{d_p}$$

推荐 $d_p=64$。融合语义进入投影器前执行 L2 归一化：

$$\bar z=\frac{z}{\|z\|_2+\epsilon}$$

投影器末端可使用 `tanh`，将类空间特征限制在有限范围，防止排序损失仅通过无限放大错误支路误差得到满足。

### 6.2 瓶颈类自编码器

每个已知体制对应一个小型对称 AE。建议结构为：

```text
64 → 32 → 16 → 32 → 64
```

或更轻量的：

```text
64 → 16 → 64
```

AE 不使用编码器到解码器的跳跃连接，避免退化成恒等映射。训练阶段可以对 $h_k$ 添加小幅高斯噪声或 dropout，使 AE 学习类内流形而不是逐点复制输入。

类 $k$ 的平均 L1 重构误差定义为：

$$e_k(x)=\frac{1}{d_p}\|h_k-AE_k(h_k)\|_1$$

除以维度能够使不同设置下的误差尺度更稳定。

## 7. 训练损失

总损失只保留三项：

$$L=L_{ce}+\lambda_{rec}L_{rec}+\lambda_{margin}L_{margin}$$

### 7.1 已知类交叉熵

$$L_{ce}=-\frac{1}{M}\sum_i\log p(y_i|x_i)$$

保证融合语义具有基本的已知类判别能力。

### 7.2 正确类重构损失

$$L_{rec}=\frac{1}{M}\sum_i e_{y_i}(x_i)$$

使样本能够在正确体制支路中低误差重构。

### 7.3 重构排序损失

$$L_{margin}=\frac{1}{M}\sum_i\max\left(0,m+e_{y_i}(x_i)-\min_{k\neq y_i}e_k(x_i)\right)$$

该损失要求正确类别的重构误差至少比最容易混淆的错误类别低 $m$，把其他已知体制作为当前类别视角下的伪未知。

建议初始设置：

- $\lambda_{rec}=1$；
- $\lambda_{margin}=0.5$；
- $m=0.2$。

最终参数只能使用已知验证集选择，不能根据测试未知类别性能调节。

## 8. 推荐训练流程

### 阶段一：语义编码预训练

1. 训练 I/Q 分支、STFT 分支、门控融合和辅助分类头；
2. 只优化 $L_{ce}$；
3. 观察训练/验证准确率和门控权重；
4. 保存验证集 Macro-F1 最优模型。

### 阶段二：联合重构训练

1. 加入 $K$ 个类投影器和瓶颈 AE；
2. 加载阶段一权重；
3. 使用完整损失联合微调；
4. 对骨干使用较小学习率，对新加入模块使用较大学习率；
5. 监控正确类误差、最难错误类误差及二者间隔。

若所有类 AE 的重构误差同时趋近于零，说明 AE 容量过大或发生恒等映射，需要缩小瓶颈、增加输入噪声或提高排序约束。

### 阶段三：误差校准

1. 冻结全部网络参数；
2. 使用从未参与梯度更新的已知校准集；
3. 对类别 $k$ 的校准样本计算匹配支路误差集合：
   $$E_k^{cal}=\{e_k(x_i):y_i=k\}$$
4. 保存每类经验分布、中位数、IQR 和候选分位点阈值；
5. 校准阶段不得使用任何测试未知类。

## 9. 类别条件误差校准与推理

### 9.1 为什么不能直接比较原始误差

不同类投影器和 AE 的正常误差尺度可能不同。如果直接执行 $\arg\min e_k$，模型可能长期偏向天然误差更小的某个 AE。

因此需要把每个误差转换到其自身类别校准分布中。

### 9.2 推荐的经验分布校准

令 $F_k$ 是 $E_k^{cal}$ 的经验累积分布，定义：

$$s_k(x)=F_k(e_k(x))$$

$s_k$ 表示当前误差在类别 $k$ 正常误差分布中的相对位置。值越小越符合类别 $k$，接近 1 表示误差位于该类正常分布尾部。

如果实现经验 CDF 不方便，也可使用稳健标准化：

$$s_k(x)=\frac{e_k(x)-\operatorname{median}(E_k^{cal})}{\operatorname{IQR}(E_k^{cal})+\epsilon}$$

两种方式在实验中选择一种作为主方法，另一种可作为补充对照。

### 9.3 推理规则

对测试样本：

1. 生成融合语义 $z$；
2. 计算 $K$ 个原始重构误差 $e_k$；
3. 通过每类校准分布转换为 $s_k$；
4. 选择候选类别：
   $$k^*=\arg\min_k s_k(x)$$
5. 比较候选类分数与阈值：
   $$\hat y=
   \begin{cases}
   k^*,&s_{k^*}(x)\leq\tau_{k^*}\\
   \mathrm{unknown},&s_{k^*}(x)>\tau_{k^*}
   \end{cases}$$

若使用经验 CDF，阈值可以直接设置为 0.90、0.95、0.99；默认从 0.95 开始，并进行敏感性实验。

用于 AUROC/AUPR 的连续未知分数可定义为：

$$S_{unk}(x)=\min_k s_k(x)$$

计算指标时必须统一分数方向：$S_{unk}$ 越大，应表示越可能为未知。

## 10. 公开数据集与实验路线

### 10.1 POWDER 主实验

[POWDER RF Fingerprinting Dataset](https://genesys-lab.org/powder)包含 IEEE 802.11a、LTE 和 5G NR 的真实空口 I/Q，覆盖四个发射基站和两个采集日。

三组开放集轮换：

1. LTE、Wi-Fi 已知，5G NR 未知；
2. 5G NR、Wi-Fi 已知，LTE 未知；
3. 5G NR、LTE 已知，Wi-Fi 未知。

推荐协议：

- Day 1：训练和已知校准；
- Day 2：最终测试；
- 补充 leave-one-base-station-out；
- 所有体制统一重采样和实际窗口时长。

### 10.2 Ghent 辅助实验

[Ghent LTE/Wi-Fi/DVB-T Dataset](https://github.com/JaronFontaine/Technology-Recognition-dataset-of-real-life-LTE-WiFi-and-DVB-T)覆盖六个真实地点。

用途：

- LTE、Wi-Fi、DVB-T 三种未知轮换；
- leave-one-location-out；
- 验证模型不是只对 POWDER 的设备和采集配置有效。

第一篇 EI 论文做到 POWDER 和 Ghent 两个数据集即可。NIST、Fraunhofer 和 TorchSig 可作为后续扩展，不纳入最低实验范围。

## 11. 基线与消融

### 11.1 基线

- 1D ResNet + 最大 softmax 概率；
- STFT 2D CNN + 最大 softmax 概率；
- OpenMax；
- 原始 CFSR 或简化复现；
- 双分支编码器 + 能量分数；
- 完整 RAT-CFSR。

基线使用完全相同的数据划分。除方法固有差异外，应尽量控制骨干容量和训练轮数。

### 11.2 核心消融

1. 仅 I/Q 分支；
2. 仅 STFT 分支；
3. 双分支直接拼接；
4. 双分支门控融合；
5. 门控融合 + 类重构；
6. 去掉 $L_{margin}$；
7. 原始误差最小与类别条件校准误差最小；
8. 普通 AE 与瓶颈 AE；
9. 不同窗口长度；
10. 窗口级随机划分与 session 级严格划分。

其中第 10 项只能用于说明数据泄漏影响，正式主结果必须使用严格划分。

## 12. 评价指标

闭集性能：

- Accuracy；
- Macro-F1；
- 每类召回率；
- 混淆矩阵。

开放集性能：

- AUROC；
- AUPR；
- OSCR；
- 未知类召回率；
- FPR@95TPR；
- 已知误拒率。

域泛化性能：

- 新日期/新地点上的已知分类准确率；
- shifted-known 误拒率；
- 新基站上的 Macro-F1。

结果至少报告 3 个随机种子的均值和标准差。

## 13. 推荐初始实现配置

- I/Q 输入：$2\times L$；
- I/Q 骨干：轻量一维 ResNet18；
- STFT 分支：三条膨胀率 1/3/5 的二维卷积支路；
- 两分支映射维度：128；
- 类投影维度：64；
- AE：64→16→64 或 64→32→16→32→64；
- 优化器：AdamW；
- 阶段一学习率：$3\times10^{-4}$；
- 阶段二骨干学习率：$3\times10^{-5}$；
- 阶段二新模块学习率：$1\times10^{-4}$；
- batch size：64；
- 模态屏蔽概率：0.1；
- $\lambda_{rec}=1$；
- $\lambda_{margin}=0.5$；
- $m=0.2$；
- 阈值初始值：经验 CDF 的 0.95 分位点。

以上均为初始工程配置，不是两篇论文的固定参数。最终配置应由已知验证集确定并在论文中明确列出。

## 14. 两篇论文的使用关系

### 来自 CFSR

- 原始 I/Q 一维骨干；
- 每类投影空间；
- 每类 AE；
- 基于重构误差的类别判断；
- 类别条件阈值；
- 其他已知类作为当前类别伪未知的训练思想。

### 来自 S3R

- STFT 时频谱构造；
- 单样本谱图归一化；
- 多膨胀率时频纹理提取；
- 类内紧凑、类间分离的语义优化思想。

### 本文新增或明确化

- I/Q 与时频语义的自适应门控融合；
- 正确类与最难错误类之间的重构排序损失；
- 瓶颈 AE 和有界类特征，避免恒等重构；
- 类别条件误差校准，解决不同 AE 误差尺度不可直接比较的问题；
- 面向体制识别的统一采样率与严格跨 session 实验协议。

## 15. 合理性与止损条件

修订后的训练、校准和推理过程在数学上保持一致：训练优化正确类重构和类间误差排序，校准解决不同类误差尺度问题，推理再以校准分数完成候选类别选择和拒识。

如果完整模型在严格跨日期、跨基站划分下，相比“双分支编码器 + 能量分数”没有稳定提升，说明类条件重构的额外复杂度没有带来实际价值。此时应保留双视图语义和门控融合，放弃类 AE，而不是继续堆叠模块。

在完成严格数据划分、两个公开数据集、主要基线和核心消融后，本方案的工作量和创新程度与一般 EI 会议论文目标基本匹配。
